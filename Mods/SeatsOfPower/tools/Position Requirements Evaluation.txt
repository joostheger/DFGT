PURPOSE
Use this file as a reference when writing new positions. Pick a prestige tier from the
comparison table and use matching Demand/Req/Stuff values. Vanilla positions are the
primary calibration points; mod positions show how custom designs compare.


FIELDS
  Demand  = DEMAND_MAX       (max demands a noble can make per cycle)
  Req     = sum of REQUIRED_BEDROOM + REQUIRED_DINING + REQUIRED_OFFICE + REQUIRED_TOMB
  Stuff   = sum of REQUIRED_CABINETS + REQUIRED_BOXES + REQUIRED_RACKS + REQUIRED_STANDS

  Most positions use the same threshold for all 4 rooms, so Req = 4 * threshold.
  Use individual values when rooms should differ (e.g. a military role with a modest bedroom
  but a fine office).


ROOM QUALITY THRESHOLDS
  Each Req component is a numeric quality floor. The in-game room name shown when the
